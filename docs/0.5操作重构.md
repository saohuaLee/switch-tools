# 0.5 操作流程与 MAC 绑定重构

更新：2026-11-05。源码版本 0.5.0，GitHub 原 0.4.1 发行包不变。

## 操作主线

启动直接进入设备中心。点击某台设备的“选择操作”，从六张任务卡中选择 MAC 绑定 / 更换、端口配置、VLAN、备份记录、运行状态或手动终端。

配置任务尚未读取设备时，显示“读取配置，继续这项操作”，读取后留在所选任务。任务标题、填写说明、返回其他操作入口固定可见。端口与 VLAN 表单填完直接审核；MAC 页底固定“下一步：审核并执行”。审核前不发送配置命令，取消后保留当前输入。

审核显示目标、前后差异、影响范围及英文命令旁的中文解释。勾选确认后，按原有基线、身份和拓扑校验执行，加密备份后逐条下发，回读验证后再保存。模拟设备明确说明不会保存真实启动配置。执行成功后当前页展示结果。

“存为批量草稿”是可选功能。需要端口、VLAN 和 MAC 多项一起提交时使用；有本机已存草稿时，直接审核会明确包含这些草稿。取消不会追加重复草稿，执行后清理当前设备草稿，其他设备草稿保持隔离。

## MAC 输入与换绑

1. 选择目标端口和用途，Cisco 默认端口安全绑定。当前端口已有绑定在左侧。
2. 新增时在右侧每行输入一个 MAC，可直接进入下一步；“整理到下方列表”仅供提前检查。不同端口也支持每行 `MAC,VLAN,完整端口`。
3. 更换时勾选旧绑定，点“更换 / 调整所选”，原 MAC 带入只读列，并定位到新 MAC 编辑格；换绑状态右侧明确提示编辑新 MAC，避免误作追加。保留新旧地址相同也可仅调整策略。
4. 上限默认按每个端口的最终静态绑定数计算，包含原有保留项；一条为 1，多条自动增加。删除部分绑定时自动收紧上限，并保留原违规动作。允许手动上限，但不能少于最终条数。
5. 违规下拉框默认 `shutdown`，支持 `restrict` 和 `protect`，英文旁附中文行为说明。

支持横线、冒号、点号、空格、连续 12 位及相应全角字符，显示整理成冒号格式，Cisco 命令转成三组四位的点号格式。缺位、非法字符、广播、组播和全零地址拒绝，不猜测或替换字符。

端口安全按关闭端口、删除旧绑定、设置策略、添加新绑定、启用端口、回读、写入启动配置的顺序执行。相邻安全草稿合并关口过程；多端口先删除涉及的旧绑定再添加新绑定。所有相关端口最终启用，即使原先禁用；最后一条删除会关闭端口安全。

## 行为限制

- 上限超过静态绑定数会允许剩余名额动态学习，界面与审核明确提示。此时不能宣称为严格白名单。
- 当前适配 Cisco IOS / IOS XE 的明确 Access 接入口，拦截上联、干道、sticky、voice、认证、聚合及未适配选项。每端口本版最多编辑 64 条静态安全 MAC，设备实际资源上限另受型号限制。
- 回读核对配置，不代表动态运行表和真实终端通断验收。动态项冲突由设备拒绝命令后停止，需在终端核对，不自动清空全局 MAC 表。
- 设备拒绝命令或回读不符时不保存；可能已部分生效、端口可能保持关闭，无自动重试或回滚。保存失败单独报告未确认，不伪装全部成功。

## 自动验证

锁定依赖 Release 构建无警告、无错误，125 项检查通过。新增检查涵盖格式兼容、按端口计数、三种违规动作、参数边界、一次换绑、迁移删除顺序、草稿隔离、删除后收紧上限、直接审核与取消保留输入、读取后继续任务、模拟执行结果、会话夹具中的验证后保存及失败不保存。STA 渲染确认 900×360 内容区域中的页底操作按钮保持可见。

使用临时工作区、会话夹具和本机回环服务，未连接真实交换机或外部 AI。真实设备、其他电脑和实际终端通断仍需验收。
