# 0.6 面向首次使用者的整体重构

更新：2026-11-06。源码及本地程序版本 0.6.0；当前 GitHub 已发行的下载包仍为 0.5.0。

## 统一规则

- 常用操作用明确的动作命名：改端口名称、换所属网络、开关端口、绑定 / 更换设备地址、创建 / 删除网络、备份配置。
- 一个操作只显示相关输入；当前值只读显示，不因为下拉框初始化、切换端口或浏览表单而生成修改。
- 采用同页步骤：连接并读取 → 选择对象 → 填写目标 → 确认 → 查看结果。返回上一步保留输入，离开流程保留现有设备数据。
- 普通操作不混入其他批量草稿；高级功能保留完整配置、命令终端、拓扑、监控、AI、批量草稿等能力。
- 页底固定上一步与下一步，并解释不能继续的原因。确认先用中文说明影响，再按需展开英文命令和中文解释。
- 失败、部分生效和保存未确认分别反馈，不用统一绿色成功提示掩盖异常。

## 截图中的端口问题

修改名称不应触发模式或 VLAN 修改。已有普通静态 MAC 安全绑定的 Cisco 接入口更换 VLAN 时，提供同步保留绑定的选项，统一预览迁移；按同一次关口完成旧绑定移除、VLAN 更换和新绑定恢复，并保留原管理启停状态。未适配的 sticky、认证、voice 等配置明确拦截，不能静默移除。

高级端口编辑会比较实际原值，剔除未变化的模式、VLAN、启停、描述和允许列表；显示“已修改字段数”也以实际变化计算。普通改名页面不再放置这些无关选项，确认页只显示原名称和新名称。

## 第一次使用

1. 在“我的交换机”添加设备。第 1 步填名称、管理地址和厂商，第 2 步填连接账户。默认真实设备；只练习时明确勾选练习设备，留空地址可生成示例地址。
2. 在设备列表点击“选择操作”。选择具体动作；不需要知道功能页、队列或厂商命令在哪里。
3. 首次配置先连接读取，再从列表勾选端口。显示中文位置和厂商完整接口名，方便对照设备。搜索支持编号、描述和网络编号。默认单口，改名、换网络、开关可以明确启用多口。
4. 当前设置只读显示。只填写所选动作需要的内容；返回上一步保留输入，退出不提交。
5. 查看中文变化与影响，按需要展开命令及中文解释。勾选已核对后确认。真实设备保留额外的实验性执行风险确认。
6. 查看独立结果页。失败、部分生效和保存未确认使用相应提示，可返回菜单或继续同类操作；没有自动回滚。

## 各项操作怎么选

| 想完成的事情 | 操作入口与填写内容 |
| --- | --- |
| 给插口写备注 | 给端口改个名字；填新名称，或明确勾选清空 |
| 把电脑分到其他网络 | 更换端口所属网络；选已有 VLAN，或在本步同步创建编号；已有静态安全绑定可一起迁移 |
| 暂停或恢复插口联网 | 打开或关闭端口；下拉框明确选择目标状态 |
| 增加允许接入的设备 | 给端口绑定设备；每行一个 MAC，保留其他已有绑定 |
| 更换电脑或网卡 | 更换已绑定的设备；从当前端口选择原地址，再填新地址 |
| 解除原地址限制 | 取消设备绑定；选择原地址，确认前仍未删除；最后一条删除会关闭端口安全 |
| 管理 VLAN | 分别选择创建、修改名称或删除网络；默认、管理和仍被引用的网络禁止删除 |
| 保存配置副本 | 备份配置；完成后在“查看备份与操作记录”查找 |

MAC 接收横线、冒号、点号、连续 12 位等写法，规范、合并重复，并按最终保留数量自动设置上限。展开“设备接入规则”可改为手动，初值接续自动计算结果；违规动作下拉框同时显示中文与 `shutdown`、`restrict`、`protect`。新端口默认 `shutdown`，已有端口带入原动作。手动上限留空位可能允许动态学习，审核保留提示。

绑定更换按关闭端口、移除旧地址、配置安全规则、添加新地址、重新打开、回读、保存执行。换 VLAN 的绑定迁移另行保留原启停状态，而不是一律打开。两种操作在确认页分别说明。

## 其他功能的入口

- “高级功能 / 高级工具”保留完整端口配置、VLAN 矩阵、静态 MAC 转发、命令终端、AI 和批量草稿。静态转发不等于限制源 MAC 接入，不能混称为设备白名单。
- “批量添加”改为选择文件、预览、确认；可保存 CSV 填写示例。出错时整批不添加。批量查找注明高级及扫描范围，不自动登录。
- 监控连接方式补充中文解释；运行状态、连接关系、异常提醒各有帮助。连线不代表实时流量，确认提醒也不代表已修复故障。
- 普通操作只执行本次计划，保留其他草稿。执行后设备基线已改变，旧草稿需重新核对。
