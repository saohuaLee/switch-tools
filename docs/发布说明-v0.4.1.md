# v0.4.1 · 网络运维工作台开发预览版

发布日期：2026-11-05。面向 Windows x64，程序包包含 .NET 运行时。

## 下载与启动

1. 下载 `NetOpsStudio-v0.4.1-win-x64.zip` 与 `SHA256SUMS.txt`。
2. 使用 `Get-FileHash .\NetOpsStudio-v0.4.1-win-x64.zip -Algorithm SHA256` 核对校验值。
3. 解压到本地目录，运行 `NetOpsStudio.exe`；无需预装 .NET。

包内包含程序、中文使用说明与版本信息，不包含设备数据库、凭据、私钥或开发者本地配置。默认数据目录为 `%LOCALAPPDATA%\NetOpsStudio\data`；已有工作区保持原样，新工作区生成明确标识的模拟设备。

## 本次改进

- 设备工作区固定显示「返回设备列表」，支持 Alt+←，返回时保留筛选、端口选择、编辑草稿与待提交变更。
- 分层组织设备身份、连接准备、功能导航与审核入口，收拢管理操作，成员和传感器明细按需展开。
- 修正总览名称列过宽、指标与表头不齐的问题；补充管理地址、数据来源和逐行查看入口。
- 修复只读地址与来源的显示绑定错误，新增实际 WPF 模板加载、数据切换与行高回归检查。

## 当前能力

包含设备建档与导入、多连接、四家实验性配置驱动、堆叠与端口选择、VLAN 与 MAC 图形化配置、统一变更审核、备份与回读、拓扑、后台监控和 AI 辅助分析。完整范围和操作步骤见仓库 README。
