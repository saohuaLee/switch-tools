# v0.5.0 · 操作流程与 MAC 绑定重构（开发预览）

发布日期：2026-11-05。适用 Windows x64，程序包自带 .NET 运行时，无需另行安装。

## 下载与启动

1. 下载 `NetOpsStudio-v0.5.0-win-x64.zip` 和 `SHA256SUMS.txt`。
2. 用 `Get-FileHash .\NetOpsStudio-v0.5.0-win-x64.zip -Algorithm SHA256` 核对校验值。
3. 完整解压 ZIP，运行 `NetOpsStudio.exe`。

包内仅包含程序、中文使用说明和版本信息，不含开发者的设备数据库、凭据、私钥或本地配置。默认数据目录为 `%LOCALAPPDATA%\NetOpsStudio\data`；已有工作区保持原样，新工作区生成明确标识的模拟设备。关闭桌面后，独立后台采集器可能继续运行，可在系统设置中停止。

## 本版变化

- 启动直接进入设备中心；选择设备后，从六张任务卡选择要完成的操作。
- 操作主线统一为“选设备 → 选任务 → 填写配置 → 本页审核执行 → 查看结果”。尚未读取时明确引导读取，取消审核保留输入；批量草稿改为可选功能。
- MAC 支持每行一条批量输入，自动整理横线、冒号、点号、空格和连续 12 位等格式，Cisco 下发统一为点号格式。
- 按每个端口的最终静态 MAC 条数自动填写 `maximum`，单条默认 1，也可手动调整；违规动作下拉框提供中文解释，默认 `shutdown`，可选择 `restrict`、`protect`。
- 换绑时并列显示原 MAC 与新 MAC，并定位到新地址编辑格；相邻安全变更合并，先关闭端口、删除旧绑定，再绑定新地址、启用端口，回读通过后自动写入启动配置。
- 审核逐条并列显示英文命令和中文说明，MAC 页底固定下一步按钮。

## 使用前请了解

端口安全当前仅适配 Cisco IOS / IOS XE 明确的 Access 接入口。`shutdown` 违规模式会使整个端口错误禁用；手动上限大于静态绑定数时，空余名额可能动态学习其他 MAC。安全操作最终会启用相关端口，即使原先已禁用。删除最后一条绑定会关闭端口安全。

命令被拒绝或回读不符时停止且不保存；变更可能部分生效，端口可能保持关闭，没有自动重试或回滚。保存失败会单独提示未确认。
