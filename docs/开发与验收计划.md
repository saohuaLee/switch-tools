# 开发与验收计划

更新日期：2026-11-03。当前版本：0.1 开发预览。完整产品分阶段开发，当前版本不等于对话中所有 P0 功能已交付。

## 第一里程碑：可运行的中文工作台

本次交付代码覆盖：设备建档与搜索、模拟端口面板、VLAN 创建、端口接入/干道配置、变更预览/确认/模拟执行、自动备份与审计、配置逐行对比、多协议 AI 客户端、实验性 SSH 只读、驱动与未来能力状态。

验收方法：

1. 运行 `tools/验证.ps1`，Release 构建无警告，功能验证程序全部通过。
2. 打开中文桌面应用，核对三台模拟设备及切换状态；搜索设备。
3. 在 VLAN 管理创建 VLAN 30，预览中查看差异和参考命令，勾选确认后执行；检查 VLAN 列表、自动备份与审计。
4. 选择接入端口，将 PVID 改为已有 VLAN，预览并执行；检查回读结果。
5. 输入非法 VLAN、选择不存在的 VLAN 或未确认执行，验证操作被拒绝且状态不变。
6. 备份当前配置，选择备份并与当前模拟状态比较；重启后档案、模拟变更、备份和审计仍在。
7. 未配置 AI 时不能发送；保存配置必须校验地址与模型；实际 API 请求只在用户发起并同意后进行。

自动验证不会访问真实设备或 AI 服务。桌面操作验收与远程兼容验收独立记录。

## 第二里程碑：实验室设备完整配置闭环

优先选定真实的华为 VRP / H3C Comware 交换机型号与固件。需要用户后续提供实验室设备类型、固件、允许测试的隔离网络及可信主机指纹；凭据由用户在软件中输入，不提交仓库。

- 提示符、分页、权限视图、回显、超时、异常中断与交互会话；SSH 公钥认证。
- Console 的串口参数、登录状态机与断线恢复；高级只读 CLI 终端及历史。
- 精确识别型号、固件、端口、VLAN 和支持能力，持久化采集时间与来源。
- 原生配置读取与语义解析；已有配置转换、互斥项清理、执行失败处理。
- 真实变更前备份、命令预览、风险确认、限流执行、回读、持久保存及重启验证。
- 仅在能力支持时提供事务回滚；不支持时展示人工恢复步骤和带外恢复要求。

完成上述验收前，真实写入入口保持关闭。配置恢复能力必须独立验证，不能将“有备份”视为“能回滚”。

## 第三里程碑：扩展厂商与日常网络配置

- 思科 IOS / IOS XE、锐捷 RGOS 的真实设备回归，以及逐步增加其他品牌。
- Telnet 显式启用与风险提示；NETCONF / RESTCONF / 厂商 API 的独立传输适配。
- CSV / Excel 导入、设备分组与归档、主动设备发现（限制目标与并发）。
- VLAN 成员矩阵、端口模板、Hybrid / Native / Voice VLAN、LACP。
- 三层接口、静态路由、DHCP；防火墙区域、策略顺序、对象、ACL、NAT 的原生语义。
- 多设备任务、取消、失败分离、备份计划与配置合规检查。

## 第四里程碑：拓扑、监控与增强 AI

LLDP / CDP 拓扑、SNMPv3、监控系统集成；多轮排障、日志分析、流式输出、本地知识库、结构化配置建议。任何 AI 建议仍须转为统一变更对象并通过确定性校验与人工确认，不能直接执行任意生成的命令。

## 尚未验证的外部能力

没有测试任何真实交换机、路由器、防火墙、串口设备或付费 AI 服务。HTTP 模拟响应只能验证协议构造与解析，不证明账户权限、模型可用性、供应商兼容性、费用或排障准确率。当前不承诺生产网络可用性。
