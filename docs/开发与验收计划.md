# 开发与验收计划

更新：2026-11-04，当前 0.2.0 开发预览。原方案和后续需求统一见 [需求对照](原方案需求对照.md)。

## 当前开发成果

工作台已按正常交换机操作流程重构；提供多连接、SSH/Console/Telnet 交互、只读 NETCONF/RESTCONF/API、真实 SSH 审核执行路径、按字段单口/批量编辑、VLAN、堆叠接口采集、MAC 绑定、CSV/XLSX 导入、限定端点发现和 AI 辅助分析。

四家系统系列驱动处于实验性实现阶段。原方案 P0 尚有缺项，不能将模拟、接口构造或会话夹具验证当成真机认证。

## 本地验收

1. 运行 `tools/验证.ps1`，检查锁定依赖、Release 构建及全部自动验证。
2. 新建独立工作区。第三台模拟设备应为双成员堆叠，分别 24 与 48 口；读取后按成员展示，共 72 个端口。
3. 跨成员选择同号端口，直接输入中文描述，确认只生成描述差异；预览审核后执行，检查原 VLAN/模式/启停不变。
4. VLAN 新建、同步分配、重命名和删除；验证默认/管理/被引用 VLAN 不能误删。
5. 批量 MAC 逐行映射、冲突拦截与删除；Cisco 模拟接入口测试源 MAC 白名单与最后一条移除。
6. 多连接档案、CSV/XLSX 导入、事务回滚、AI 默认配置及切换草稿分别检查。
7. 打包并启动包含运行时的 Windows x64 应用；旧数据不覆盖，新工作区可体验新模拟数据。

## 真机验收范围

后续在用户授权的隔离环境执行，不将缺少真机作为限制软件开发范围的理由。凭据保留在本地设备表单，不发到聊天或仓库。

- 核对型号、固件、权限、主机指纹、端口命名与堆叠编号，对常见及异常输出建立回归夹具。
- 验证 iStack/IRF/Cisco/VSU 的在线/离线、成员增减、更换、主备切换、不同口数、上联口与逻辑口区分。
- 验证 SSH 分页、提示符、错误、超时、取消及部分生效处理；Console/Telnet 手动交互和编码单独验收。
- 验证静态 MAC 的真实转发关系；源 MAC 白名单的允许/拒绝行为、动态学习/voice/认证冲突与恢复。
- 核对真实配置变更前备份、精确字段修改、回读、启动配置保存和重启持久性。
- 回滚/恢复必须单独开发和验证；有备份不等于可自动回滚。

## 后续开发顺序

1. 完善常见交换机命令与产品系列：Hybrid/Native/Voice、速率/双工、聚合、其他厂商端口安全与 IP+MAC、机框/特殊堆叠、准确型号/固件回填。
2. 完善 P0：真实语义配置差异、恢复流程、完整终端、多设备任务、AI 流式/多轮/连接测试和结构化建议。
3. P1：三层接口、静态路由、DHCP、ACL、安全区域/防火墙策略、NAT、自动化任务。
4. P2：LLDP/CDP 拓扑、SNMPv3、监控和告警。

每一项分别记录实现、夹具验证、真机验收和生产边界；未经验证的能力不标记为已认证。
