# 0.3 浅色工作台重构

2026-11-04。用户已授权开发：以功能完成为基础，重点重构 UI 和操作逻辑，统一浅色主题；本轮加入拓扑、设备在线状态、CPU、内存、温度、趋势和告警。

工作主线：网络总览 → 拓扑/告警定位 → 设备工作区 → 端口/VLAN/MAC 编辑 → 变更审核 → 执行结果。全局设置与设备操作分层；设备工作区保留当前设备、成员、所选端口、草稿与采集时间。

浅色规范：雾灰页面、白色工作面、深色文字、蓝色主操作；状态同时使用文字与颜色；统一间距/控件高度/焦点；大数据区避免多层嵌套滚动和拥挤侧栏。

控件补充：统一圆角白色下拉框，独立箭头、浅蓝选中项与蓝色焦点，保留普通选择及可输入 VLAN；滚动条采用细圆角轨道/滑块，保留滚轮、拖动、横向滚动及悬停反馈。后台刷新以当前设备为准，不以旧列表行反向切换设备。

监控：只读 SNMPv3/SNMPv2c 或已有 SSH 档案；真实设备默认未启用；凭据 DPAPI。独立后台采集进程使用当前 Windows 用户，可在桌面窗口关闭后继续运行；采集端停止/休眠标为过期，不能批量误报设备离线。数据库顺序增加表，保留旧数据。

状态：可达与指标采集质量分开；缺失/错误/过期不显示 0。连续失败后判不可达，恢复记录事件；CPU/内存持续阈值，温度按用户设定阈值且保留传感器名称/来源。堆叠指标未取得成员归属时不推断为所有成员。

拓扑：LLDP/CDP 邻居采集、标识匹配、两端接口、堆叠信息、未知邻居、来源/时间/过期、手工连接、布局保存、缩放/拖动与设备跳转。自动邻居与手工连接分别保存。

验收：协议/解析/状态机/持续告警/过期/拓扑去重/后台生命周期自动验证；浅色桌面实际操作、原有批量配置回归；自包含发布并启动；README 与源码一起提交推送，核对 Private 和远端。

本地结果：锁定还原与 Release 构建 0 警告/0 错误，104 项验证通过；完成单文件桌面启动、下拉菜单/可输入 VLAN、跨成员选择、中文描述、MAC 表格与提交回读检查。关闭桌面后后台采集继续，停止信号可退出。详细证据见《验证记录》；没有真机或外部 AI 验收。
